# /ai-usage — отчёт по AI-исполнителям

Два контура, считаются и отчитываются ОТДЕЛЬНО:
- **Внешние исполнители** — `codex`, `corp-claude`. Отдельные машины/логины, задача уходит наружу и возвращается отчётом.
- **Личные агенты** — `local-agent`: субагенты Agent-тула и workflow-агенты, работают внутри моей сессии.

Источники (глобальные, в `~/.claude/`):
- `ai-usage.md` — вердикты приёмки (✅/🟡/❌ + почему) и живые скоуборды обоих контуров.
- `exec-telemetry/corp.jsonl` и `exec-telemetry/personal.jsonl` — сырые события Stop-хука (`capture-ai-usage.sh` → `telemetry.py`), контуры РАЗДЕЛЕНЫ: корпоративный (Codex, corp-claude, отчёты корпа) и личный (субагенты и workflow-агенты). Поля сверх расхода: `duration_s`, `source_class`, `adapter`, `parent_session`.
- `ai-usage-raw.jsonl` — тот же поток ДО 20.08.2026, заморожен. Для периодов до этой даты читать его, после — два файла выше. Событий из обоих источников на одну сессию не бывает.
- **Свёрнутые агрегаты.** События старше `TELEMETRY_RETAIN_DAYS` (30) заменяются суточными строками с `"aggregate": true` (поля `date`, `executor`, `sessions`, `total_tokens`, `output_tokens`). Их НЕ смешивать с сырыми при подсчёте сессий: агрегат уже несёт их число.
- `exec-telemetry/personal-friction.jsonl` — события `SubagentStop` (`capture-friction.sh`): `agent_type`, `outcome`, `verification_state`, `source_class`. Джойнится к `local-agent` по `agent_id`. `friction_state` там всегда `unavailable` — наличие секции «Трение» по телеметрии не определяется, этот показатель не считать. Легаси `friction-raw.jsonl` удалён 02.09.2026 (в него никто не писал с v2).
- Дополнительно по запросу: `find ~/.codex/sessions -name '*.jsonl'` → total_token_usage (точный расход Codex), `~/.claude-corp/tasks/done/REPORT_*.md` (объём и качество отчётов корпа).

### Как читать токены (иначе цифра врёт в разы)

- **Брать последнее событие на прогон, НЕ сумму событий.** Ключ прогона: `agent_id` у личных агентов, `session` у остальных. Токен-события помечены `"cumulative":true` — живой прогон переотправляется на каждом Stop. Июль: 204 события против 49 сессий, сумма завышала расход в 4,4 раза.
- **Не сравнивать исполнителей по `total_tokens`.** У всех 95-97% объёма — чтение кэша, оно на порядок дешевле. Сравнивать по `output_tokens` и вводу без кэша (Codex: `input - cached_input`; корп и личные агенты: `input + cache_creation`).
- **`last_turn_tokens` — исторический ключ** (события до 10.08): расход одного хода, не итог сессии. В расчёт периода не брать; июль закрыт бэкфиллом с `"backfill":true`.

## Шаги

1. **Период**: из аргументов; иначе текущая неделя. Преобразовать в [from, to].
2. **Собрать**: вердикты из `ai-usage.md` за период + события из `exec-telemetry/*.jsonl` (плюс `ai-usage-raw.jsonl` для дат до 20.08), фильтр по ts. Сверить: событие без вердикта = «принято без оценки» — перечислить отдельно (дыры приёмки).
3. **Отчёт — двумя раздельными блоками**, не сваливать в одну таблицу:
   - **Внешние исполнители** (Codex, корп): задач · ✅/🟡/❌ · характерные успехи/провалы (1 фраза) · расход (прогоны, ввод без кэша, output). Здесь вердикт ожидается на каждую задачу — простой исполнителя тоже находка.
   - **Личные агенты** (`local-agent`): прогонов · разбивка по `agent_type` из `personal-friction.jsonl` · сколько из них workflow-агентов · расход · разбивка по `outcome`/`verification_state` (доля прогонов с секцией «Трение» по телеметрии недоступна — не подставлять вместо неё другую цифру). Вердиктов здесь по одному на прогон НЕ ждать — оценивается пачка (воркфлоу, волна субагентов), а не каждый агент; дыра приёмки считается по пачкам без вердикта, не по прогонам.
   - **Рекомендации раздачи**: подтвердить/скорректировать колонку «Правило раздачи» в обоих скоубордах по свежим фактам. Изменилось → обновить `ai-usage.md` (скоуборды живые, дубли не плодить).
   - **Дыры**: пачки без вердикта, исполнители без задач (простаивающий ресурс — например Codex), прогоны с `agent_type: unknown` (нечем атрибутировать).
4. Кратко, таблицами. Без пересказа задач — только пригодность исполнителей.

## Правило ведения (для оркестратора, вне этого скилла)
При приёмке результата — одна строка в `ai-usage.md` под текущий месяц (`echo >> `, бесплатно), в свой раздел: внешние исполнители — построчно на задачу; личные агенты — на ПАЧКУ (воркфлоу целиком, волна субагентов, чип-сессия), а не на каждый прогон. Вердикт честный: ❌ с уроком ценнее ✅. Скоуборды рефакторить при смене картины, не плодить строки.
